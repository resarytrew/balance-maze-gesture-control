# Balance Maze — Premium UI / Вторая итерация

## Визуальные изменения

- **Панель слева сверху**: размер, расположение, Georgia-заголовок, латунная рамка, декоративные элементы, бейдж сложности и подпись уровня приближены к предоставленному референсу.
- **Панель справа**: фиксированная ширина 374 px для широкого экрана, компактная вертикальная структура, тёмно-коричневое стекло, тонкие латунные границы, контролируемая прокрутка на маленьких экранах.
- **Превью камеры**: близкое к референсу соотношение сторон, состояния выключенной камеры, отсутствия рук и калибровки; поверх видеопотока остаётся линия между отслеживаемыми ладонями.
- **Кнопки и слайдер**: текстурные янтарные акценты, настоящие состояния выбора и клавиатурный фокус.
- **Advanced Settings**: работает как раскрывающаяся секция. В неё перенесены два реально разных режима управления («Доска в руках» / «Высота ладоней»), техническая информация об алгоритме и остановка камеры. Не добавлены фиктивные функции управления одной рукой — они помечены как недоступные.
- **Панель уровней, кнопка Show Controls, режим показа**: переработаны в единый стиль.
- **3D-композиция**: при ширине окна от 1180 px камера игрового мира немного смещена, чтобы доска не уходила под веб-панель. Физические координаты и условия столкновений не изменены.
- **Внешний деревянный корпус и внутренний бортик**: добавлены процедурные прозрачные декоративные текстуры с уникальными растительными завитками и розетками, создающими эффект ручной резьбы. Это 3D-декали, а не настоящая скульптурная геометрия рельефа; фотографическая точность приложенного концепт-рендера не гарантируется.

## Что осталось прежним

Физика, уровни, генератор, MediaPipe, горячие клавиши, режимы наклона, логика падения и победы. Все существующие игровые функции сохранены.

## Как запустить в Windows PowerShell

```powershell
npm install
npm run dev
```

Открой URL, указанный Vite, обычно `http://localhost:3000`.

## Что проверить после запуска

1. При разрешении 1920×1080 справа видна панель, не перекрывающая доску.
2. `Camera` включает камеру, `Mouse` и `WASD` переключают управление.
3. Режимы `Board in Hands` / `Hand Height` доступны в `Advanced Settings`.
4. `Auto Calibrate (C)` запускает калибровку, когда камера включена.
5. `Show Controls` разворачивает игровую панель; `P` скрывает интерфейс настройки.
6. Орнамент не перекрывает игровой путь, лунки и металлический шарик.
